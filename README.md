# Euro Trans Logistics Platform

Створи сучасний, динамічний та повністю адаптивний веб-сайт та платформу для логістичної компанії "Euro Trans Logistics".

Основна інформація:

Назва: Euro Trans Logistics

Локація: Україна, м. Первомайськ, Миколаївська область.

Мова інтерфейсу: Українська.

Стилістика: Професійний, індустріальний, але технологічний дизайн. Колірна гама: глибокий синій (trust), яскраво-оранжевий або жовтий (action/logistics), білий та світло-сірий.

Структура сайту (Navigation):

Головна: Hero-секція з потужним закликом до дії (CTA), статистикою (км подолано, тонн перевезено), основними перевагами.

Про компанію: Історія, акцент на базу в м. Первомайськ, автопарк.

Послуги: Картки послуг (Міжнародні перевезення, Внутрішні рейси по Україні, Перевезення негабаритних вантажів, Зерновози).

Калькулятор: Інтерактивна форма розрахунку вартості (Звідки -> Куди, вага, тип вантажу).

Трекінг: Імітація інтерфейсу відстеження вантажу за номером ТТН.

Контакти: Карта (Первомайськ), форма зворотного зв'язку, кнопки месенджерів (Viber, Telegram).

Функціональні особливості:

Адаптивність: Сайт має ідеально виглядати на iPhone, Android та десктопах.

Компоненти: Використовуй Lucide-react для іконок (вантажівки, склади, глобус).

Анімації: Плавна поява елементів при скролі (framer-motion).

Dashboard для клієнта: Створи макет особистого кабінету, де клієнт може бачити свої замовлення та статус поточної доставки.

Технічні вимоги:

React + Vite + Tailwind CSS.

Використовуй бібліотеку компонентів shadcn/ui.

Весь текст на сайті має бути українською мовою.
